# Theme Presets

Personalizing ORMI is simpler now. The old theme editor has been replaced with a preset-based theme picker, so you can switch the app look in a couple of clicks instead of tweaking individual color tokens.

## Preset selector in the navbar

There is now a dedicated theme preset picker in the top bar. Open it, choose a preset, and the new look is applied immediately.

## Amber is now the default look

New sessions now start with the Amber theme by default. If you have already selected a different theme, your saved choice is still respected.

## New themes can appear automatically

Themes are now loaded as preset files, which means new looks can be added over time without changing the picker itself. When a new preset is published, it can show up directly in the selector.

## Easy reset

If you want to go back to the standard experience, the picker still includes a reset option that returns you to the default theme.
