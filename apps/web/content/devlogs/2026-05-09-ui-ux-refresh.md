# UI and UX Refresh

ORMI received a broad UI and UX refresh focused on clarity, consistency, and reducing rough edges across the main product surfaces.

## Cleaner public-facing pages

The home page has been reworked to feel more like a product entry point and less like a prototype. Messaging is clearer, the layout is more balanced, and the overall presentation is closer to the rest of the design system.

## Better authentication flow

The sign-in and sign-up pages now share the same visual direction as the landing page. The auth flow is more focused, the content is easier to scan, and the forms sit inside a cleaner, more intentional layout.

## More consistent dashboard surfaces

Dashboard-related UI was also refined to better match the rest of the application. Workspace cards now communicate their layout type more clearly, and several interface elements were adjusted to feel more coherent and polished.
