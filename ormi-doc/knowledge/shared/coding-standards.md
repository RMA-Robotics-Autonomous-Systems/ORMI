# Coding Standards

> Internal source-of-truth knowledge base. When it disagrees with code, this file
> wins — update it and the LikeC4 model in lockstep on structural changes.

**This is a pointer doc, not a copy.** The single source of truth for coding
standards is the repo root **`AGENTS.md`** — it owns the monorepo placement rules,
the Core Immutability Rule, the 9 required implementation patterns, the workflow,
and the Definition of Done. Read it directly; do not restate the patterns here.

The 9 patterns (see `AGENTS.md` for each in full):

1. API responses via `apiResponse(data, status)` — never raw `Response`/`NextResponse.json`.
2. Zod validation on every mutating route (POST/PUT/PATCH/DELETE).
3. Contexts via `createSafeContext<T>(name)`.
4. Plugin definitions in `export.ts`.
5. Datasource providers are plain lifecycle components when their context value is null/unused.
6. Auth routes wrapped with `withAuth(handler)`.
7. Server-side Prisma access only through `apps/web/server/prisma-*.ts` helpers.
8. Widget gating via `filterWidgetsByDatasources`.
9. Client HTTP via the shared `HttpClient` + domain API wrappers (returning `ApiResult<T>`).
10. `WidgetDefinition.Component` must be a stable, module-level reference.

## Knowledge-base-specific rules worth surfacing

These are architectural invariants that live in `AGENTS.md`'s guardrails but
recur across this knowledge base — captured here as short pointers with _why_.

| Rule                                         | Why it matters                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Core immutability** (`packages/ormi-core`) | Touching core needs explicit approval, an impact analysis, and updated docs in `apps/web/content/docs`. Core is the stable contract every plugin binds to.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Subscribe/advertise refcount idempotency** | The subscription registry re-flushes subscribe intents on every reconnect. Without a per-topic refcount a reconnect opens duplicate subscriptions; `unsubscribe` must no-op on unknown/in-flight topics. Open/close the real sub only on the 0↔1 transition. See `data-flow.md`.                                                                                                                                                                                                                                                                                                           |
| **Single shared Jotai `appStore`**           | The app has exactly one store, `appStore` (`packages/ormi-core/src/store.ts`), and `<Provider store={appStore}>` wraps the tree. Every out-of-React writer (`processTFMessage`, `setRemoteCalls`, …) must target it. A write to `getDefaultStore()`/an ad-hoc `createStore()` is invisible to `useAtomValue`, which then silently reports empty/stale state (stranded the remote-call explorer and rostainer buttons). Reads pin the store: `useAtomValue(atom, { store: appStore })`.                                                                                                     |
| **React Compiler + external mutable stores** | The web app builds `reactCompiler: true`; it infers memo deps from the callback body and strips no-op reads. Never key a `useMemo` on a version counter whose value the body ignores (`void version; …, [version]`) — the compiler drops the dead read and freezes the memo on its first result (stranded every TF widget on stale data in prod). Read external mutable state through `useSyncExternalStore` with an identity-stable, change-fresh snapshot; derived memos consume that snapshot as a real dependency. Reference: `packages/ormi-core/src/transforms/transform-hooks.tsx`. |
| **HTTPS + `ws://` robots → main thread**     | Production serves over HTTPS while robots expose plain `ws://`. The browser's insecure-content exception applies to the document, **not** to web workers, so a worker WebSocket to a `ws://` robot is impossible. The foxglove insecure-URL → main-thread routing is deliberate; do not "fix" it toward the worker path. Optimize the main-thread path instead.                                                                                                                                                                                                                            |
| **Main-thread decode budgeting**             | On the main-thread path, coalesce-to-latest-before-decode only relieves topics faster than the drain rate. Expensive payloads (e.g. PointCloud2) also need a per-topic decode-rate cap (coalesce to LATEST above the ceiling, never drop the newest) and a per-tick decode time budget that yields the event loop, so a heavy burst can't starve the fanout/render loop. Shed frames stay visible via the produced-vs-delivered drop ratio — never hide them.                                                                                                                              |
| **Error Handling Rule**                      | When a user pastes an error message, explain the likely cause and propose a fix for them to apply — do not auto-patch. Behavioral override in `AGENTS.md`.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **No plan-doc references in code/docs**      | Do not cite uncommitted `*_PLAN.md` docs, phase numbers, or plan labels in committed content.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Commit hygiene**                           | No `Co-Authored-By` or other agent/tool attribution in commit messages. Keep a terse rolling `TODO.md` at the repo root.                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
